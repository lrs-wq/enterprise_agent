可通过局域网或受控公网反向代理访问；模型与知识数据均保留在本机。

## 获取项目与仓库内容

```bash
git clone git@github.com:lrs-wq/enterprise_agent.git
cd enterprise_agent
```

仓库包含后端与前端代码、测试、安装与部署脚本、配置示例、回答边界策略、
运营校对知识、项目文档与截图、功能说明 PDF，以及 `outputs/` 中的问答用例和评测报告。

模型权重不上传到 Git。`.gitignore` 已排除模型目录、Ollama 本地存储和
GGUF、SafeTensors、PyTorch、ONNX 等模型文件；仓库仅保留模型名称及调用配置。
`.env`、`data/` 运行数据、`uploads/` 原始导入资料、日志、缓存和文档制作临时目录
也不提交，配置模板使用 `.env.example`。

首次克隆后需要单独准备模型和业务资料。安装脚本会生成本机 `.env` 与管理员令牌，
应用会创建运行数据目录；将原始业务文档放入 `uploads/` 后按下方说明导入、审核并发布。
`deploy/` 中的常驻服务配置和公网同步脚本包含当前部署机器的绝对路径，
在其他机器部署时需要先调整路径及隧道目标。

## 首次安装

项目统一使用 Conda，不使用系统 Python：

```bash
bash scripts/setup-local.sh
```

请先将 Conda 和 Ollama 加入当前终端的 `PATH`，并在克隆后的项目目录执行命令。
确认 Ollama 已启动并下载模型：

```bash
ollama pull qwen3.5:9b-mlx
ollama pull bge-m3
```

`qwen3.5:9b-mlx` 是当前本地部署使用的模型标签。目标环境需提供该标签；
若使用其他已部署模型，可在 `.env` 中调整 `AI_AGENT_CHAT_MODEL` 和
`AI_AGENT_EMBEDDING_MODEL`。模型文件保留在运行机器的模型存储中。

## 导入现有资料

默认批量导入 `uploads/` 原始资料和 `knowledge/curated/` 运营校对资料：

```bash
conda run -n company-ai-agent \
  python scripts/import-existing.py
```

重复内容依据 SHA-256 自动跳过。原文件不会移动或修改，系统副本保存在
`data/documents/`，索引保存在 `data/knowledge.db`。新导入资料默认为草稿，须在
管理后台选择“公司资料”或“产品资料”；产品资料可继续绑定所属品牌与产品标识。
“审核并发布”后才会参与公司/产品问答。每份文档都有独立二级页，可查看全部分片和
从原文提取的图片，并可修改图片标题、替代文本、产品标识和展示状态。

已发布内容使用不可变版本快照。运营修改会生成待审核草稿，当前公开版本继续服务；
审核发布时文字、归属、片段和图片原子切换。后台可查看发布历史、撤回或回滚公开版本，
回滚不会覆盖较新的草稿。公开文字和图片只读取本公司归属的活动快照。

## 启动与访问

```bash
bash scripts/run-local.sh
```

- 本机聊天页：<http://127.0.0.1:8000/>
- 知识库管理页：<http://127.0.0.1:8000/admin>
- 同一局域网设备：`http://本机局域网IP:8000/`
- 公网聊天页：<https://ai.hzzootech.com/company-ai/>
- 公网管理页：<https://ai.hzzootech.com/company-ai/admin>
- API 文档：<http://127.0.0.1:8000/docs>

公网反向代理与常驻隧道的部署说明见
[docs/public-routing.md](docs/public-routing.md)。

知识库管理页会要求管理员令牌。首次执行 `scripts/setup-local.sh` 会自动生成令牌；
现有环境可在项目目录执行以下命令查看：

```bash
rg '^AI_AGENT_ADMIN_TOKEN=' .env
```

令牌只保存在后台页面的 `sessionStorage`，关闭浏览器会话后需重新输入。
同一客户端 300 秒内连续认证失败 5 次会被临时限速。换发令牌时可通过
`AI_AGENT_ADMIN_PREVIOUS_TOKEN` 和明确的 UTC 到期时间提供短暂过渡窗口。

服务只将 Web 端口监听在 `0.0.0.0:8000`；Ollama 仍仅监听本机
`127.0.0.1:11434`。局域网测试结束后按 `Ctrl+C` 停止服务。

问题先经过服务端的急症、诊疗、隐私、第三方品牌、明确无关话题及主体歧义等边界检查。
对普通公司、产品和养宠问法，本地 Qwen 返回结构化主题类别，服务端据此选择公司资料、
产品资料或通用养宠路径；模型判为诊疗、第三方或无关话题时由服务端返回范围提示，
无法判明则请用户澄清。明确的自有品牌或型号可直接进入已发布资料检索。
公司和产品回答仍须经过已发布资料检索与逐条引用校验；主题分类不能直接授权生成答案。
问题提到草稿、撤回或旧文档时，主题仍按所问对象分类，资料是否可用由后续证据校验决定。
省略主语的养宠追问（如“喜欢玩什么？”）会把近期用户原话交给主题分类模型判断；确认承接后，服务端核对品种确实出现在用户原话中，再补入生成问题。此过程不依赖固定犬种词表；当前问题明确换品种或话题时不沿用前文，无法确认主体时请用户说明宠物种类或品种。

应用默认仅允许 1 个完整聊天请求执行、2 个请求等待；超出容量时 JSON 接口返回
HTTP 429，已开始的 SSE 请求则发送带 `status=429` 的错误事件。
同机多个应用 worker 使用 `data/runtime_capacity.db` 共享执行与排队槽位，异常退出的
槽位由心跳租约回收。跨主机部署仍需独立的共享协调设施。
聊天从排队到最终校验共用 75 秒截止时间，同一客户端默认 60 秒最多提交 12 次。模型生成会给最终校验和响应预留 7 秒；初稿未通过证据校验时，修复生成最多使用 30 秒，并在修复超时后优先返回已通过校验的删减答案或已审核原文摘录。没有安全答案时仍返回明确的超时错误。
生成期间页面提供取消按钮；页面通过 `/api/chat/stream` 接收真实排队、检索、生成与
校验进度，只在完成后展示已校验答案，不会提前展示未经校验的模型正文。旧版
`/api/chat` JSON 接口仍可使用。取消会尽力终止上游模型请求并释放应用容量；同步文档解析和
图片提取运行在独立子进程，取消时终止子进程及其 OCR 子进程。
无上下文、无私人或时变内容的已校验公开文本问答可短时缓存；每次命中仍复核公开
版本及来源状态，发布或撤回会改变缓存键或使旧结果失效。

### 隔离问答评测

全量问答用例必须通过隔离执行器运行。执行器为每条用例创建独立的 SQLite 快照，
真正应用空库、草稿、撤回、过期、模型故障和对话历史等前置条件，不会改写源知识库：

```bash
conda run -n company-ai-agent \
  python scripts/run-qa-evaluation.py \
  --output outputs/公司智能助手_隔离评测结果.csv
```

结果会同时记录实际状态、证据状态、路由原因码、最终结果原因码、失败阶段、失败字段、
前置条件实况和执行错误。后续版本可使用上一次结构化结果检查新增回归：

```bash
conda run -n company-ai-agent \
  python scripts/run-qa-evaluation.py \
  --baseline outputs/公司智能助手_隔离评测结果.csv \
  --output outputs/公司智能助手_本次评测结果.csv
```

可重复传入 `--case-id QA-001` 只复跑指定用例。原测试用例 CSV 始终只读；每完成一条
用例，结果文件都会原子更新，以便模型中断后保留已完成的检查点。

## 输出与“思考过程”

接口返回固定结构：回答状态、证据状态、回退类型、决策码与策略版本、标题、摘要、
分节正文、拒答或限制回答的具体原因、可审计分析摘要、来源引用、产品图片及耗时。
系统不再显示未经校准的置信度百分比。页面默认展示答案和必要来源，策略版本、内部
原因码、耗时及分析摘要放在折叠的“技术详情”中；不会暴露模型原始隐藏推理，也不
保存 Ollama 返回的原始思考 token。

公司与产品回答由模型为摘要和每个分节分别返回结构化来源编号；服务端确认来源属于
实际上下文，并逐断言核对肯否方向、限定范围及“型号—属性—数值—单位—条件”后，
才渲染可见 `[Sx]`。每个来源都必须直接支持所在回答块中的具体断言，展示摘录也取自
对应支撑原文；图片使用独立的 `[Mx]` 来源并直接绑定图片自己的页码或表格行。系统
不会根据相似度猜测或补造来源。拒答、澄清和混合范围限制通过
`answer.refusal_reason` 返回人类可读原因；前端只在它能提供非重复信息时显示独立卡片。
`fallback_kind` 区分真实部分回答、仅范围说明、缺少证据和服务故障。混合品牌或非紧急
混合医疗问题只把可独立回答的本公司部分交给模型处理。
